# 모바일 웨딩 청첩장

## 실행 방법
1. 압축을 해제합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 사진은 `assets` 폴더의 로컬 이미지 파일을 사용합니다.

## 수정할 내용
- 신랑/신부 이름, 날짜, 시간, 예식장 주소: `index.html`
- 계좌번호: `.account-card`의 표시 텍스트와 `data-copy` 값을 함께 수정
- 구글 지도 목적지: `index.html` 안의 Google Maps 링크의 검색어를 실제 예식장으로 변경
- 색상과 여백: `style.css`

현재 이름, 날짜, 장소, 계좌번호는 시안 기반 예시 정보입니다.
